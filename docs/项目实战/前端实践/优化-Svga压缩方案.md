# 优化：SVGA 压缩方案

## 背景

SVGA 动画在活动页里视觉效果很好，但体积通常不小。一个页面如果同时加载多个动画资源，很容易拉长首屏时间，弱网环境下体验更明显。

## 优化思路

- 优先清理无效图层、无效帧和冗余位图资源。
- 能用序列帧的场景，不一定都要用 SVGA。
- 位图素材优先做压缩，避免把大图直接塞进动画包。
- 长动画考虑拆分成多个小动画，按需加载。

## 落地方案

1. 设计侧统一导出规范，限制尺寸、帧数和透明区域。
2. 开发侧增加资源体积校验，超过阈值直接拦截。
3. 页面运行时按曝光时机或交互时机懒加载。
4. 对高频复用动画结合本地缓存减少重复下载。

## 注意点

- 压缩过度会导致动画边缘发虚或掉帧。
- 动画拆分后要注意衔接时机，否则会出现闪烁。
- 不是所有动画都值得压缩到极致，核心是平衡体积与观感。
