# Transformer与大模型基础

## Transformer架构

### 核心组件

**Self-Attention机制**
- 计算query、key、value
- 注意力权重 = softmax(QK^T / √d_k)
- 输出 = Attention × V

**Multi-Head Attention**
```
MultiHead(Q,K,V) = Concat(head_1,...,head_h)W^O
head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
```

**Position Encoding**
- 正弦位置编码：PE(pos, 2i) = sin(pos/10000^(2i/d))
- 可学习位置编码

### 模型结构

**Encoder-Decoder架构**
- Encoder: Self-Attention + FFN
- Decoder: Masked Self-Attention + Cross-Attention + FFN
- 残差连接 + Layer Normalization

**GPT架构（Decoder-only）**
- 仅使用Decoder部分
- 自回归生成
- 适合文本生成任务

### 生产级框架

**Hugging Face Transformers**
```python
from transformers import GPT2Config, GPT2LMHeadModel, Trainer

# 从零训练GPT-2
config = GPT2Config(
    vocab_size=50257,
    n_positions=1024,
    n_embd=768,
    n_layer=12,
    n_head=12
)
model = GPT2LMHeadModel(config)

training_args = TrainingArguments(
    output_dir="./gpt2-scratch",
    per_device_train_batch_size=8,
    num_train_epochs=3,
    learning_rate=5e-5
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset
)
trainer.train()
```

**特点**
- 统一的Trainer API
- 自动分布式训练
- 130K+ GitHub stars
- 支持几乎所有主流模型

## 常见问题

**Q: 从零训练vs微调？**
- 从零训练: 需大量数据和算力
- 微调: 利用预训练模型，效果好

**Q: 如何选择框架？**
- 学习: nanoGPT
- 研究: Hugging Face
- 生产: PyTorch Lightning
- 超大规模: Megatron-LM

**Q: GPU显存不足？**
- 减小batch size
- 使用Gradient Accumulation
- 启用DeepSpeed ZeRO
- 量化/蒸馏模型
