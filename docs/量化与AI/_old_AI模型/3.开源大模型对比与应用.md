## 顶级开源模型

### 1. Llama 3.3 ⭐⭐⭐⭐⭐

**基本信息**
- 公司: Meta
- 发布: 2024年12月
- 规模: 70B (Llama 3.1: 8B/70B/405B)

**开源程度**
```
✅ 模型权重完全开源
✅ 推理代码开源
✅ 微调代码开源
✅ 训练代码开源(torchtune)
⚠️ 训练数据部分开源
```

**性能特点**
- 接近GPT-4水平
- 完全免费商用
- 社区最活跃
- 支持工具调用

**下载使用**
```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.3-70B-Instruct",
    device_map="auto",
    torch_dtype=torch.float16
)
tokenizer = AutoTokenizer.from_pretrained(
    "meta-llama/Llama-3.3-70B-Instruct"
)

# 推理
inputs = tokenizer("分析比特币趋势", return_tensors="pt")
outputs = model.generate(**inputs, max_length=200)
print(tokenizer.decode(outputs[0]))
```

**推荐理由**
- 最好的开源模型
- 生态最完善
- 文档最齐全

## 本地部署方案

### 方案1: Ollama (最简单)

```bash
# 安装
curl -fsSL https://ollama.com/install.sh | sh

# 运行Llama 3.3
ollama run llama3.3

# 运行Qwen 2.5
ollama run qwen2.5:72b

# API调用
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.3",
  "prompt": "预测股票走势的方法"
}'
```

### 方案2: vLLM (高性能)

```bash
# 安装
pip install vllm

# 启动服务
python -m vllm.entrypoints.openai.api_server \
  --model meta-llama/Llama-3.3-70B-Instruct \
  --dtype half \
  --gpu-memory-utilization 0.9
```

### 方案3: Hugging Face Transformers

```python
from transformers import pipeline

# 创建pipeline
pipe = pipeline(
    "text-generation",
    model="meta-llama/Llama-3.3-70B-Instruct",
    device_map="auto"
)

# 使用
result = pipe(
    "分析比特币价格走势",
    max_length=500
)
print(result[0]['generated_text'])
```

model = AutoModelForCausalLM.from_pretrained(

## 微调方案

### LoRA微调
```python
from peft import LoraConfig, get_peft_model

# 配置LoRA
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none"
)

# 应用到模型
model = get_peft_model(base_model, lora_config)

# 训练
trainer = Trainer(
    model=model,
    train_dataset=dataset,
    args=training_args
)
trainer.train()
```

### QLoRA (量化+LoRA)
```python
from transformers import BitsAndBytesConfig

# 4-bit量化配置
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16
)

# 加载模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.3-70B",
    quantization_config=bnb_config
)

# 微调(显存需求大幅降低)
```

## 选型建议

**综合能力**: Llama 3.3 70B
- 性能最强
- 生态最好
- 免费商用

**中文任务**: Qwen 2.5 72B
- 中文理解最佳
- 国内支持好
- 文档齐全

**资源有限**: Mistral 7B
- 小而强
- 本地可跑
- 效率高

**数学推理**: DeepSeek V3 或 QwQ-32B
- 推理能力强
- 适合量化
- 逻辑严密

**生产部署**: vLLM + Llama 3.3
- 高性能推理
- 稳定可靠
- 易于扩展

## 成本对比

**闭源API**
- GPT-4: $0.03-0.12 / 1K tokens
- Claude: $0.015-0.075 / 1K tokens
- Gemini: 免费额度有限

**开源自部署**
- 硬件成本: 一次性
- 运维成本: 可控
- 完全私有化
- 无使用限制

**混合方案**
- 开发: 本地开源模型
- 生产: 闭源API + 开源fallback
