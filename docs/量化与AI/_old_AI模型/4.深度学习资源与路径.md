# 深度学习资源与路径

## 系统学习路径

### 初学者路径 (1-2个月)

**第一步: 理解原理**
- 资源: Annotated Transformer
- 网址: http://nlp.seas.harvard.edu/annotated-transformer/
- 内容: 逐行注释的Transformer实现
- 时间: 1周

**第二步: 动手实践**
- 资源: nanoGPT
- 网址: github.com/karpathy/nanoGPT
- 内容: 从零实现GPT
- 时间: 2-3周

**第三步: 工具使用**
- 资源: Hugging Face Course
- 网址: huggingface.co/learn/nlp-course
- 内容: Transformers库实战
- 时间: 2-3周

### 进阶路径 (3-6个月)

**工程化训练**
- PyTorch Lightning
- 分布式训练
- 模型优化

**大规模预训练**
- Megatron-LM
- DeepSpeed
- 数据并行/模型并行

**领域应用**
- FinGPT (金融)
- Qlib (量化)
- 时间序列预测

## 实践项目

### 入门项目

**1. 情感分析**
```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
result = classifier("比特币今天大涨")
print(result)
```

**2. 文本生成**
```python
generator = pipeline("text-generation", model="gpt2")
text = generator("量化交易策略", max_length=100)
```

### 进阶项目

**3. 模型微调**
```python
from transformers import Trainer

trainer = Trainer(
    model=model,
    train_dataset=train_data,
    eval_dataset=eval_data
)
trainer.train()
```
