# Diffusion模型原理

## 核心思想

### 基本概念

Diffusion模型（扩散模型）是一类通过**逐步添加噪声**和**逐步去噪**来生成数据的生成模型。

**核心过程**
1. **正向扩散（Forward Diffusion）**: 逐步向数据添加噪声，直到变成纯噪声
2. **反向去噪（Reverse Denoising）**: 学习从噪声逐步恢复到原始数据

**直观理解**
```
原始图像 → [加噪] → 噪声图 → [去噪] → 生成图像
   x_0   →  ...  →  x_T   →  ...  →   x_0'
```

## 数学原理

### 前向扩散过程

**马尔可夫链**
```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t) · x_{t-1}, β_t · I)
```

- `x_t`: t时刻的噪声数据
- `β_t`: 噪声调度系数（通常递增）
- `N`: 高斯分布

**封闭形式（重参数化技巧）**
```
x_t = √(α̅_t) · x_0 + √(1-α̅_t) · ε

其中:
α_t = 1 - β_t
α̅_t = ∏(i=1 to t) α_i
ε ~ N(0, I)
```

**关键性质**
- 可以直接从 `x_0` 采样得到任意时刻 `x_t`
- 无需逐步计算，提高训练效率

### 反向去噪过程

**目标**: 学习反向分布
```
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))
```

**参数化方式**
```
方式1 (DDPM): 预测噪声 ε_θ(x_t, t)
μ_θ(x_t, t) = 1/√α_t · (x_t - (1-α_t)/√(1-α̅_t) · ε_θ(x_t, t))

方式2: 直接预测 x_0
x̂_0 = 1/√α̅_t · (x_t - √(1-α̅_t) · ε_θ(x_t, t))
```

### 训练目标

**变分下界（ELBO）**
```
L_simple = E_t,x_0,ε [||ε - ε_θ(x_t, t)||²]
```

**解释**
- 随机选择时间步 `t`
- 从 `x_0` 添加噪声得到 `x_t`
- 训练网络预测添加的噪声 `ε`

**简化版损失函数**
```python
def diffusion_loss(model, x_0):
    # 1. 随机采样时间步
    t = torch.randint(0, T, (batch_size,))

    # 2. 采样噪声
    eps = torch.randn_like(x_0)

    # 3. 添加噪声
    x_t = sqrt_alpha_bar[t] * x_0 + sqrt_one_minus_alpha_bar[t] * eps

    # 4. 预测噪声
    eps_pred = model(x_t, t)

    # 5. 计算损失
    loss = F.mse_loss(eps_pred, eps)
    return loss
```

## 采样算法

### DDPM采样（原始）

```python
def ddpm_sample(model, x_T):
    x = x_T  # 从纯噪声开始

    for t in reversed(range(T)):
        # 1. 预测噪声
        eps_pred = model(x, t)

        # 2. 计算均值
        alpha_t = alpha[t]
        alpha_bar_t = alpha_bar[t]

        mean = (1 / sqrt(alpha_t)) * (
            x - (1 - alpha_t) / sqrt(1 - alpha_bar_t) * eps_pred
        )

        # 3. 添加随机性
        if t > 0:
            z = torch.randn_like(x)
            sigma_t = sqrt(beta[t])
            x = mean + sigma_t * z
        else:
            x = mean

    return x
```

### DDIM采样（加速）

**确定性采样**
```
x_{t-1} = √α̅_{t-1} · x̂_0 + √(1-α̅_{t-1}) · ε_θ(x_t, t)

其中:
x̂_0 = (x_t - √(1-α̅_t) · ε_θ(x_t, t)) / √α̅_t
```

**优势**
- 确定性过程，可跳步采样
- 从1000步降到50步，速度提升20倍
- 生成质量相近

```python
def ddim_sample(model, x_T, skip_steps=20):
    x = x_T
    time_steps = list(range(0, T, skip_steps))[::-1]

    for i, t in enumerate(time_steps):
        # 预测噪声
        eps_pred = model(x, t)

        # 预测x_0
        x_0_pred = (x - sqrt(1 - alpha_bar[t]) * eps_pred) / sqrt(alpha_bar[t])

        if i < len(time_steps) - 1:
            t_prev = time_steps[i + 1]
            # 直接跳到t_prev
            x = sqrt(alpha_bar[t_prev]) * x_0_pred + \
                sqrt(1 - alpha_bar[t_prev]) * eps_pred
        else:
            x = x_0_pred

    return x
```

## 网络架构

### U-Net架构

**基本结构**
```
编码器 (Encoder):
  Input → Conv → ResBlock → DownSample → ... → Bottleneck

解码器 (Decoder):
  Bottleneck → UpSample → ResBlock → Conv → ... → Output

跳跃连接:
  编码器各层 → 对应解码器层
```

**时间嵌入**
```python
class TimeEmbedding(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, t):
        # Sinusoidal embedding
        half_dim = self.dim // 2
        emb = math.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim) * -emb)
        emb = t[:, None] * emb[None, :]
        emb = torch.cat([emb.sin(), emb.cos()], dim=-1)
        return emb
```

**条件注入**
```python
class ResBlock(nn.Module):
    def forward(self, x, t_emb):
        h = self.conv1(x)

        # 注入时间信息
        h = h + self.time_mlp(t_emb)[:, :, None, None]

        h = self.conv2(h)
        return x + h
```

## 改进变体

### Latent Diffusion (Stable Diffusion)

**核心思想**: 在潜在空间而非像素空间做扩散

```
图像 → [VAE编码] → 潜在向量 → [扩散过程] → [VAE解码] → 生成图像
  x   →          →    z       →            →           →    x'
```

**优势**
- 计算量降低 8-64倍
- 训练速度快
- 生成质量高

**架构**
```python
class LatentDiffusion:
    def __init__(self):
        self.vae = AutoencoderKL()      # VAE编码器/解码器
        self.unet = UNet()              # 扩散模型
        self.text_encoder = CLIP()       # 文本编码器

    def forward(self, img, text):
        # 1. 编码到潜在空间
        z = self.vae.encode(img)

        # 2. 文本条件
        c = self.text_encoder(text)

        # 3. 扩散训练
        loss = self.diffusion_loss(z, c)
        return loss

    def sample(self, text, steps=50):
        # 1. 文本条件
        c = self.text_encoder(text)

        # 2. 潜在空间采样
        z = self.ddim_sample(c, steps)

        # 3. 解码到像素空间
        img = self.vae.decode(z)
        return img
```

### Classifier-Free Guidance

**无分类器引导**: 提升条件生成质量

```
ε̃_θ(x_t, c) = ε_θ(x_t, ∅) + w · (ε_θ(x_t, c) - ε_θ(x_t, ∅))

w: 引导权重（通常7.5）
c: 条件（如文本）
∅: 空条件
```

**实现**
```python
def guided_diffusion(x_t, t, text, w=7.5):
    # 条件预测
    eps_cond = model(x_t, t, text)

    # 无条件预测
    eps_uncond = model(x_t, t, "")

    # 引导
    eps_guided = eps_uncond + w * (eps_cond - eps_uncond)

    return eps_guided
```

### Score-Based Models

**等价形式**: 预测分数函数（梯度）

```
分数函数: s_θ(x_t, t) = ∇_x log p(x_t)

关系: ε_θ(x_t, t) = -√(1-α̅_t) · s_θ(x_t, t)
```

**Langevin动力学采样**
```python
def langevin_sample(score_model, x_T):
    x = x_T
    for t in reversed(range(T)):
        # 计算分数
        score = score_model(x, t)

        # Langevin更新
        x = x + step_size * score + sqrt(2 * step_size) * noise

    return x
```

## 优缺点分析

### 优势

✅ **生成质量高**
- 图像质量媲美GAN
- 模式崩溃问题少

✅ **训练稳定**
- 目标函数简单
- 无需对抗训练

✅ **理论基础扎实**
- 基于变分推断
- 数学推导严密

- 易于添加条件

### 劣势

- 推理时间长

- 内存占用大

- U-Net模型复杂

## 代码实现示例

### 完整DDPM实现

```python
import torch
import torch.nn as nn

class SimpleDDPM:
    def __init__(self, model, T=1000):
        self.model = model
        self.T = T

        # 噪声调度
        self.beta = torch.linspace(1e-4, 0.02, T)
        self.alpha = 1 - self.beta
        self.alpha_bar = torch.cumprod(self.alpha, dim=0)

    def add_noise(self, x_0, t, eps):
        """前向扩散"""
        sqrt_alpha_bar = torch.sqrt(self.alpha_bar[t])
        sqrt_one_minus_alpha_bar = torch.sqrt(1 - self.alpha_bar[t])

        return sqrt_alpha_bar * x_0 + sqrt_one_minus_alpha_bar * eps

    def train_step(self, x_0):
        """训练一步"""
        batch_size = x_0.shape[0]

        # 随机时间步
        t = torch.randint(0, self.T, (batch_size,))

        # 随机噪声
        eps = torch.randn_like(x_0)

        # 添加噪声
        x_t = self.add_noise(x_0, t, eps)

        # 预测噪声
        eps_pred = self.model(x_t, t)

        # 损失
        loss = nn.MSELoss()(eps_pred, eps)
        return loss

    @torch.no_grad()
    def sample(self, shape):
        """采样生成"""
        x = torch.randn(shape)

        for t in reversed(range(self.T)):
            # 预测噪声
            eps_pred = self.model(x, torch.tensor([t]))

            # 去噪
            alpha_t = self.alpha[t]
            alpha_bar_t = self.alpha_bar[t]

            mean = (1 / torch.sqrt(alpha_t)) * (
                x - (1 - alpha_t) / torch.sqrt(1 - alpha_bar_t) * eps_pred
            )

            if t > 0:
                noise = torch.randn_like(x)
                sigma = torch.sqrt(self.beta[t])
                x = mean + sigma * noise
            else:
                x = mean

        return x
```

## 总结

Diffusion模型通过**逐步去噪**的方式生成高质量数据：

**核心原理**
1. 前向过程逐步添加噪声
2. 反向过程学习去噪
3. 训练目标为噪声预测

**关键技术**
- 重参数化技巧实现高效训练
- DDIM实现快速采样
- Latent Diffusion降低计算成本
- Classifier-Free Guidance提升质量

**应用方向**
- 图像生成（Stable Diffusion）
- 时间序列预测（TimeGrad）
- 金融信号生成
- 条件生成任务
