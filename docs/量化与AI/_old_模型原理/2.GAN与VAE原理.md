# GAN与VAE原理

## GAN (生成对抗网络)

### 核心思想

**对抗训练**: 生成器(Generator)与判别器(Discriminator)相互博弈

```
生成器: 噪声 → 假数据，目标是骗过判别器
判别器: 真/假数据 → 真假概率，目标是区分真假
```

**博弈过程**
```
1. 生成器生成假数据
2. 判别器判断真假
3. 生成器根据判别器反馈改进
4. 判别器提升判别能力
5. 循环直到纳什均衡
```

### 数学原理

**目标函数（Minimax Game）**
```
min_G max_D V(D,G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]

其中:
- D(x): 判别器判断x为真的概率
- G(z): 生成器从噪声z生成的数据
- E_x: 真实数据期望
- E_z: 噪声期望
```

**分解理解**
```
判别器目标 (最大化):
  max_D E_x[log D(x)] + E_z[log(1 - D(G(z)))]
  → 真实样本判为真，生成样本判为假

生成器目标 (最小化):
  min_G E_z[log(1 - D(G(z)))]
  → 让生成样本被判为真
```

**理论最优解**
```
当 p_data = p_g 时:
D*(x) = 1/2 (任何输入都无法区分)
min_G max_D V(D,G) = -log(4)
```

### 训练算法

```python
def train_gan(generator, discriminator, real_data):
    # === 训练判别器 ===
    # 1. 真实数据
    real_labels = torch.ones(batch_size, 1)
    d_loss_real = criterion(discriminator(real_data), real_labels)

    # 2. 生成数据
    z = torch.randn(batch_size, latent_dim)
    fake_data = generator(z)
    fake_labels = torch.zeros(batch_size, 1)
    d_loss_fake = criterion(discriminator(fake_data.detach()), fake_labels)

    # 3. 判别器总损失
    d_loss = d_loss_real + d_loss_fake
    d_optimizer.zero_grad()
    d_loss.backward()
    d_optimizer.step()

    # === 训练生成器 ===
    z = torch.randn(batch_size, latent_dim)
    fake_data = generator(z)
    g_loss = criterion(discriminator(fake_data), real_labels)  # 希望被判为真

    g_optimizer.zero_grad()
    g_loss.backward()
    g_optimizer.step()
```

### GAN变体

#### DCGAN (Deep Convolutional GAN)

**架构改进**
```
生成器:
  Input(z) → Linear → Reshape
  → ConvTranspose2d (upsample)
  → BatchNorm → ReLU
  → ConvTranspose2d → BatchNorm → ReLU
  → ConvTranspose2d → Tanh
  → Output(image)

判别器:
  Input(image)
  → Conv2d → LeakyReLU
  → Conv2d → BatchNorm → LeakyReLU
  → Conv2d → BatchNorm → LeakyReLU
  → Flatten → Linear → Sigmoid
  → Output(prob)
```

**关键技巧**
- 用卷积替代全连接
- BatchNorm稳定训练
- LeakyReLU防止梯度消失
- 去掉Pooling层

#### WGAN (Wasserstein GAN)

**核心改进**: 使用Wasserstein距离

```
原始GAN问题:
- 判别器过强导致梯度消失
- 训练不稳定
- 模式崩溃

WGAN解决方案:
- 使用Wasserstein距离度量分布差异
- 判别器改为Critic（输出实数）
- Weight Clipping保证Lipschitz约束
```

**损失函数**
```
L_D = E_x[D(x)] - E_z[D(G(z))]  (最大化)
L_G = -E_z[D(G(z))]             (最小化)

约束: ||D||_L ≤ 1 (Lipschitz)
```

**实现**
```python
def train_wgan(critic, generator, real_data):
    # 训练Critic
    for _ in range(n_critic):  # 多次训练Critic
        real_score = critic(real_data)
        fake_data = generator(torch.randn(batch_size, z_dim))
        fake_score = critic(fake_data)

        # Wasserstein距离
        c_loss = -(real_score.mean() - fake_score.mean())
        c_loss.backward()
        c_optimizer.step()

        # Weight clipping
        for p in critic.parameters():
            p.data.clamp_(-0.01, 0.01)

    # 训练生成器
    fake_data = generator(torch.randn(batch_size, z_dim))
    g_loss = -critic(fake_data).mean()
    g_loss.backward()
    g_optimizer.step()
```

#### StyleGAN

**核心创新**: 风格注入机制

```
传统: z → G → image
StyleGAN: z → Mapping Network → w → Synthesis Network → image

风格注入:
  w → AdaIN (Adaptive Instance Normalization)
  → 控制每一层的风格
```

**AdaIN机制**
```python
def adaptive_instance_norm(x, style):
    # x: feature map [B, C, H, W]
    # style: 风格向量 [B, C]

    # Instance Normalization
    mean = x.mean(dim=[2, 3], keepdim=True)
    std = x.std(dim=[2, 3], keepdim=True)
    normalized = (x - mean) / (std + 1e-8)

    # 风格调制
    gamma, beta = style.chunk(2, dim=1)
    out = gamma * normalized + beta
    return out
```

**优势**
- 风格控制精细
- 生成质量极高
- 支持风格混合

#### Conditional GAN (cGAN)

**条件生成**: 加入额外信息

```
无条件: z → G → x
条件: (z, c) → G → x

c: 条件（类别、文本、图像等）
```

**实现**
```python
class ConditionalGenerator(nn.Module):
    def __init__(self, z_dim, num_classes):
        self.embed = nn.Embedding(num_classes, z_dim)
        self.gen = nn.Sequential(...)

    def forward(self, z, labels):
        # 条件嵌入
        c = self.embed(labels)
        # 拼接或相加
        input = torch.cat([z, c], dim=1)  # 或 z + c
        return self.gen(input)
```

### 优缺点

**优势**
✅ 生成质量高（尤其StyleGAN）
✅ 不需要显式密度估计
✅ 生成速度快（单次前向）

**劣势**
❌ 训练不稳定
❌ 模式崩溃问题
❌ 需要平衡G和D
❌ 梯度消失风险

## VAE (变分自编码器)

### 核心思想

**概率生成模型**: 学习数据的潜在表示

```
编码: x → q(z|x) → z (推断潜在变量)
解码: z → p(x|z) → x̂ (生成数据)

关键: 潜在空间服从先验分布 p(z) = N(0,I)
```

**直观理解**
```
输入图像 → 编码器 → (μ, σ) → 采样z → 解码器 → 重建图像
             ↓                   ↓
          分布参数          重参数化采样
```

### 数学原理

**变分推断**

目标: 最大化边际似然
```
log p(x) = log ∫ p(x|z)p(z)dz
```

难点: 积分不可解

**ELBO (Evidence Lower Bound)**
```
log p(x) ≥ E_q[log p(x|z)] - KL(q(z|x) || p(z))
         = -重建损失      - KL散度

其中:
q(z|x) = N(μ(x), σ²(x))  # 编码器输出
p(z) = N(0, I)           # 先验
p(x|z) = Decoder(z)      # 解码器
```

**损失函数**
```
L_VAE = 重建损失 + β·KL散度

重建损失 = ||x - x̂||² (MSE) 或 -log p(x|z) (BCE)
KL散度 = -0.5 * Σ(1 + log σ² - μ² - σ²)
```

### 重参数化技巧

**问题**: 采样操作不可微

**解决方案**
```
原始: z ~ N(μ, σ²)
重参数化: z = μ + σ·ε, 其中 ε ~ N(0,I)
```

**实现**
```python
class VAE(nn.Module):
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        z = mu + eps * std  # 可微
        return z

    def forward(self, x):
        # 编码
        mu, logvar = self.encoder(x)

        # 重参数化采样
        z = self.reparameterize(mu, logvar)

        # 解码
        x_recon = self.decoder(z)

        return x_recon, mu, logvar

def vae_loss(x, x_recon, mu, logvar):
    # 重建损失
    recon_loss = F.mse_loss(x_recon, x, reduction='sum')

    # KL散度
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())

    return recon_loss + kl_loss
```

### VAE变体

#### β-VAE

**目标**: 增强解耦表示

```
L = 重建损失 + β·KL散度

β > 1: 更强的解耦，更模糊的重建
β < 1: 更好的重建，较弱的解耦
```

**应用**
- 可解释特征学习
- 风格迁移
- 表示学习

#### VQ-VAE (Vector Quantized VAE)

**核心**: 离散潜在空间

```
连续VAE: x → z(连续) → x̂
VQ-VAE: x → z_e → 量化 → z_q → x̂
```

**量化过程**
```python
class VectorQuantizer(nn.Module):
    def __init__(self, num_embeddings, embedding_dim):
        self.codebook = nn.Embedding(num_embeddings, embedding_dim)

    def forward(self, z_e):
        # 找最近的codebook向量
        distances = torch.cdist(z_e, self.codebook.weight)
        indices = distances.argmin(dim=-1)

        # 量化
        z_q = self.codebook(indices)

        # Straight-through estimator
        z_q = z_e + (z_q - z_e).detach()

        return z_q, indices
```

**应用**
- DALL-E的基础
- 高质量图像生成
- 离散表示学习

#### CVAE (Conditional VAE)

**条件生成**
```
编码: (x, c) → q(z|x,c) → z
解码: (z, c) → p(x|z,c) → x̂

c: 条件（标签、属性等）
```

**实现**
```python
class CVAE(nn.Module):
    def forward(self, x, c):
        # 拼接条件
        input = torch.cat([x, c], dim=1)

        # 编码
        mu, logvar = self.encoder(input)
        z = self.reparameterize(mu, logvar)

        # 解码（加入条件）
        z_c = torch.cat([z, c], dim=1)
        x_recon = self.decoder(z_c)

        return x_recon, mu, logvar
```

### 优缺点

**优势**
✅ 训练稳定
✅ 理论基础扎实
✅ 潜在空间平滑
✅ 支持插值

**劣势**
❌ 生成质量不如GAN
❌ 重建可能模糊
❌ 后验崩塌问题
❌ KL消失问题

## GAN vs VAE 对比

| 维度 | GAN | VAE |
|-----|-----|-----|
| **训练方式** | 对抗训练 | 变分推断 |
| **生成质量** | 高（清晰） | 中（可能模糊） |
| **训练稳定性** | 差 | 好 |
| **潜在空间** | 无约束 | 服从先验N(0,I) |
| **模式覆盖** | 差（模式崩溃） | 好 |
| **理论保证** | 弱 | 强 |
| **可解释性** | 弱 | 强 |
| **速度** | 快 | 快 |

**选择建议**
- 图像生成质量优先 → GAN (StyleGAN)
- 表示学习/编辑 → VAE (β-VAE)
- 稳定训练 → VAE
- 条件生成 → cGAN或CVAE
- 最佳方案 → 结合两者优势（如VAE-GAN）

## 代码实践

### 完整VAE实现

```python
class SimpleVAE(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()

        # 编码器
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)

        # 解码器
        self.fc3 = nn.Linear(latent_dim, hidden_dim)
        self.fc4 = nn.Linear(hidden_dim, input_dim)

    def encode(self, x):
        h = F.relu(self.fc1(x))
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def decode(self, z):
        h = F.relu(self.fc3(z))
        return torch.sigmoid(self.fc4(h))

    def forward(self, x):
        mu, logvar = self.encode(x.view(-1, 784))
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

# 训练
def train_vae(model, data_loader):
    for x, _ in data_loader:
        x_recon, mu, logvar = model(x)

        # 损失
        recon_loss = F.binary_cross_entropy(x_recon, x.view(-1, 784), reduction='sum')
        kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
        loss = recon_loss + kl_loss

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

### 完整GAN实现

```python
class SimpleGAN:
    def __init__(self):
        self.G = Generator()
        self.D = Discriminator()
        self.criterion = nn.BCELoss()

    def train_step(self, real_data):
        batch_size = real_data.size(0)

        # === 训练D ===
        # 真实数据
        real_labels = torch.ones(batch_size, 1)
        real_output = self.D(real_data)
        d_loss_real = self.criterion(real_output, real_labels)

        # 假数据
        z = torch.randn(batch_size, latent_dim)
        fake_data = self.G(z).detach()
        fake_labels = torch.zeros(batch_size, 1)
        fake_output = self.D(fake_data)
        d_loss_fake = self.criterion(fake_output, fake_labels)

        d_loss = d_loss_real + d_loss_fake
        self.d_optimizer.zero_grad()
        d_loss.backward()
        self.d_optimizer.step()

        # === 训练G ===
        z = torch.randn(batch_size, latent_dim)
        fake_data = self.G(z)
        output = self.D(fake_data)
        g_loss = self.criterion(output, real_labels)

        self.g_optimizer.zero_grad()
        g_loss.backward()
        self.g_optimizer.step()

        return d_loss.item(), g_loss.item()
```

## 总结

**GAN核心**
- 对抗训练机制
- 生成高质量样本
- 训练不稳定需技巧

**VAE核心**
- 变分推断框架
- 重参数化采样
- 稳定但可能模糊

**实践建议**
1. 图像生成 → GAN (StyleGAN)
2. 表示学习 → VAE (β-VAE)
3. 时间序列 → 两者结合
4. 量化应用 → 根据场景选择
