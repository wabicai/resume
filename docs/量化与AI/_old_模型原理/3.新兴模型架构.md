# 新兴模型架构

## State Space Models (SSM)

### 核心思想

**状态空间表示**: 用隐状态建模序列

```
状态方程: h_t = A·h_{t-1} + B·x_t
输出方程: y_t = C·h_t + D·x_t

h_t: 隐状态
x_t: 输入
y_t: 输出
A,B,C,D: 可学习参数
```

**优势**
- 建模长序列高效
- 计算复杂度线性O(L)
- 类似RNN但可并行训练

### S4 (Structured State Space)

**HiPPO理论**: 高效记忆机制

**核心创新**
```
传统SSM: 参数A需精心初始化
S4: 使用HiPPO矩阵初始化A

HiPPO矩阵性质:
- 最优多项式投影
- 捕获长期依赖
- 数值稳定
```

**离散化**
```python
# 从连续到离散
def discretize(A, B, C, dt):
    """
    零阶保持（ZOH）离散化
    """
    I = np.eye(A.shape[0])
    A_discrete = expm(A * dt)
    B_discrete = np.linalg.solve(A, (A_discrete - I) @ B)
    return A_discrete, B_discrete, C

# S4使用对角加低秩分解加速
A = Λ - P @ P.T  # 对角 - 低秩
```

**高效计算（卷积视角）**
```python
def s4_layer(x, A, B, C):
    L = x.shape[1]  # 序列长度

    # 1. 计算SSM核
    K = compute_kernel(A, B, C, L)  # O(L log L)

    # 2. 卷积（FFT加速）
    y = fft_conv(x, K)  # O(L log L)

    return y

def compute_kernel(A, B, C, L):
    """计算卷积核"""
    # 利用Cauchy核性质快速计算
    # K = [C·B, C·A·B, C·A²·B, ..., C·A^(L-1)·B]
    return cauchy_kernel(A, B, C, L)
```

**代码实现**
```python
class S4Layer(nn.Module):
    def __init__(self, d_model, d_state):
        super().__init__()
        self.d_state = d_state

        # HiPPO初始化
        self.A = nn.Parameter(make_HiPPO(d_state))
        self.B = nn.Parameter(torch.randn(d_state, 1))
        self.C = nn.Parameter(torch.randn(1, d_state))
        self.D = nn.Parameter(torch.randn(1))

    def forward(self, x):
        # 离散化
        A_bar, B_bar = discretize(self.A, self.B, dt=1.0)

        # 计算卷积核
        K = compute_ssm_kernel(A_bar, B_bar, self.C, x.shape[1])

        # FFT卷积
        y = fft_conv1d(x, K)

        return y + self.D * x
```

**优势**
- 处理长序列（100K tokens）
- 训练并行化
- 推理可递归（RNN模式）

## Mamba

### 核心创新

**选择性SSM**: 动态调整状态空间参数

```
传统SSM: A,B,C固定
Mamba: A,B,C = f(x)  # 输入依赖
```

**动机**
- Transformer: 注意力开销O(L²)
- S4: 固定参数，表达力受限
- Mamba: 选择性机制 + 线性复杂度

### 选择性扫描

**机制**
```python
def selective_scan(x):
    # 1. 动态生成SSM参数
    B = linear_B(x)  # [B, L, D]
    C = linear_C(x)  # [B, L, D]
    Δ = linear_delta(x)  # [B, L, D] 时间步长

    # 2. 离散化（输入依赖）
    A_bar = exp(Δ * A)
    B_bar = Δ * B

    # 3. 选择性扫描
    h = torch.zeros(B, D)
    outputs = []

    for t in range(L):
        h = A_bar[:, t] * h + B_bar[:, t] * x[:, t]
        y = C[:, t] * h
        outputs.append(y)

    return torch.stack(outputs, dim=1)
```

**硬件感知设计**
```
问题: 动态参数阻止卷积优化

解决: 硬件感知扫描算法
- Kernel Fusion (融合操作)
- Recomputation (重计算节省内存)
- Parallel Scan (并行前缀和)
```

**并行扫描算法**
```python
def parallel_scan(A, X):
    """
    并行计算累积:
    y_t = A_t * y_{t-1} + X_t

    O(log L)并行复杂度
    """
    L = X.shape[1]

    # 分治递归
    if L == 1:
        return X

    # 奇偶分组
    A_even = A[:, ::2]
    A_odd = A[:, 1::2]
    X_even = X[:, ::2]
    X_odd = X[:, 1::2]

    # 合并
    A_combined = A_odd * A_even
    X_combined = A_odd * X_even + X_odd

    # 递归
    Y = parallel_scan(A_combined, X_combined)

    # 还原
    return interleave(Y, A_even * Y + X_even)
```

**架构**
```python
class MambaBlock(nn.Module):
    def __init__(self, d_model, d_state):
        super().__init__()
        self.d_state = d_state

        # 输入投影
        self.in_proj = nn.Linear(d_model, 2 * d_model)

        # SSM参数生成
        self.conv1d = nn.Conv1d(d_model, d_model, 3, padding=1, groups=d_model)
        self.x_proj = nn.Linear(d_model, d_state * 2 + 1)  # B, C, Δ

        # 固定A (S4风格)
        self.A = nn.Parameter(make_A(d_state))

        # 输出投影
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x):
        # 门控投影
        x, z = self.in_proj(x).chunk(2, dim=-1)

        # 短卷积
        x = self.conv1d(x.transpose(1, 2)).transpose(1, 2)
        x = F.silu(x)

        # 生成SSM参数
        B, C, delta = self.x_proj(x).split([self.d_state, self.d_state, 1], dim=-1)

        # 选择性扫描
        y = selective_scan(x, self.A, B, C, delta)

        # 门控输出
        y = y * F.silu(z)

        return self.out_proj(y)
```

**性能对比**
```
模型         | 复杂度  | 长序列 | 速度
------------|--------|-------|------
Transformer | O(L²)  | ❌    | 慢
S4          | O(L)   | ✅    | 快
Mamba       | O(L)   | ✅    | 很快

Mamba优势:
- 线性复杂度
- 硬件优化
- 表达力强（选择性）
```

## Flow-based Models

### 核心思想

**可逆变换**: 精确密度估计

```
x → f → z (正向)
z → f⁻¹ → x (逆向)

要求:
1. f可逆
2. f可微
3. 雅可比行列式易算
```

**优势**
- 精确似然 log p(x) = log p(z) + log|det J_f|
- 双向映射（生成+编码）
- 训练稳定

### Normalizing Flows

**变量替换公式**
```
p_x(x) = p_z(f(x)) · |det J_f(x)|

J_f: 雅可比矩阵
det J_f: 行列式
```

**简单Flow: Planar Flow**
```python
class PlanarFlow(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.u = nn.Parameter(torch.randn(dim))
        self.w = nn.Parameter(torch.randn(dim))
        self.b = nn.Parameter(torch.randn(1))

    def forward(self, z):
        # f(z) = z + u * tanh(w^T z + b)
        lin = torch.matmul(z, self.w) + self.b
        f_z = z + self.u * torch.tanh(lin)

        # log|det J|
        psi = (1 - torch.tanh(lin)**2) * self.w
        det = 1 + torch.matmul(psi, self.u)
        log_det = torch.log(torch.abs(det))

        return f_z, log_det
```

### RealNVP

**Coupling Layers**: 高效可逆变换

```
输入: x = [x_1, x_2]  # 分成两部分

正向:
  y_1 = x_1
  y_2 = x_2 ⊙ exp(s(x_1)) + t(x_1)

逆向:
  x_1 = y_1
  x_2 = (y_2 - t(x_1)) ⊙ exp(-s(x_1))

雅可比行列式:
  det J = exp(Σ s(x_1))  # O(1)计算
```

**实现**
```python
class CouplingLayer(nn.Module):
    def __init__(self, dim, hidden_dim):
        super().__init__()
        self.dim = dim
        self.split = dim // 2

        # s和t网络
        self.s_net = nn.Sequential(
            nn.Linear(self.split, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, dim - self.split)
        )
        self.t_net = nn.Sequential(
            nn.Linear(self.split, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, dim - self.split)
        )

    def forward(self, x, reverse=False):
        x1, x2 = x.split([self.split, self.dim - self.split], dim=-1)

        if not reverse:
            # 正向
            s = self.s_net(x1)
            t = self.t_net(x1)
            y2 = x2 * torch.exp(s) + t
            log_det = s.sum(dim=-1)
            return torch.cat([x1, y2], dim=-1), log_det
        else:
            # 逆向
            s = self.s_net(x1)
            t = self.t_net(x1)
            x2 = (x2 - t) * torch.exp(-s)
            return torch.cat([x1, x2], dim=-1)

    def sample(self, z):
        return self.forward(z, reverse=True)
```

### Glow

**改进RealNVP**
1. 1×1可逆卷积
2. ActNorm层
3. 多尺度架构

**1×1可逆卷积**
```python
class InvConv1x1(nn.Module):
    def __init__(self, channels):
        super().__init__()
        # 初始化为随机正交矩阵
        W = torch.qr(torch.randn(channels, channels))[0]
        self.W = nn.Parameter(W)

    def forward(self, x, reverse=False):
        if not reverse:
            # 正向
            weight = self.W.view(channels, channels, 1, 1)
            z = F.conv2d(x, weight)
            log_det = torch.slogdet(self.W)[1] * h * w
            return z, log_det
        else:
            # 逆向
            weight = torch.inverse(self.W).view(channels, channels, 1, 1)
            x = F.conv2d(z, weight)
            return x
```

**ActNorm (激活归一化)**
```python
class ActNorm(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.scale = nn.Parameter(torch.ones(1, channels, 1, 1))
        self.bias = nn.Parameter(torch.zeros(1, channels, 1, 1))
        self.initialized = False

    def forward(self, x):
        if not self.initialized:
            # 数据依赖初始化
            with torch.no_grad():
                mean = x.mean(dim=[0, 2, 3], keepdim=True)
                std = x.std(dim=[0, 2, 3], keepdim=True)
                self.bias.data = -mean
                self.scale.data = 1 / (std + 1e-6)
            self.initialized = True

        z = (x + self.bias) * self.scale
        log_det = self.scale.abs().log().sum() * h * w
        return z, log_det
```

## Retentive Networks (RetNet)

### 核心思想

**保留机制**: 结合Transformer和RNN优势

```
Transformer: 并行训练，O(L²)推理
RNN: O(1)推理，串行训练
RetNet: 并行训练，O(1)推理 ✅
```

**三种等价形式**
```python
# 1. 并行表示（训练）
Q = XW_Q
K = XW_K
V = XW_V
Retention = (Q @ K.T ⊙ D) @ V  # D是衰减矩阵

# 2. 循环表示（推理）
S_t = γS_{t-1} + K_t^T V_t
O_t = Q_t @ S_t

# 3. 分块循环表示（高效推理）
```

**衰减矩阵**
```
D_ij = {
  γ^(i-j), if i ≥ j
  0,       if i < j
}

γ ∈ (0,1): 衰减因子
```

**实现**
```python
class MultiScaleRetention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads

        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)

        # 不同head不同衰减率
        self.gamma = nn.Parameter(
            1 - 2 ** (-5 - torch.arange(num_heads, dtype=torch.float))
        )

    def forward_parallel(self, x):
        """并行计算（训练）"""
        B, L, D = x.shape

        Q = self.W_Q(x).view(B, L, self.num_heads, self.head_dim)
        K = self.W_K(x).view(B, L, self.num_heads, self.head_dim)
        V = self.W_V(x).view(B, L, self.num_heads, self.head_dim)

        # 构建衰减矩阵
        decay = self.gamma.view(1, 1, -1, 1)
        indices = torch.arange(L).view(L, 1) - torch.arange(L).view(1, L)
        D = torch.where(indices >= 0, decay ** indices.unsqueeze(-1), 0)

        # Retention
        retention = (Q @ K.transpose(-2, -1) * D) @ V

        return retention.reshape(B, L, D)

    def forward_recurrent(self, x_t, state):
        """循环计算（推理）"""
        Q_t = self.W_Q(x_t)
        K_t = self.W_K(x_t)
        V_t = self.W_V(x_t)

        # 更新状态
        state = self.gamma * state + K_t.T @ V_t

        # 输出
        output = Q_t @ state

        return output, state
```

**优势**
- 训练并行（如Transformer）
- 推理O(1)（如RNN）
- 无需KV缓存
- 性能与Transformer相当

## RWKV

### 核心思想

**RNN with Attention**: 线性注意力的RNN形式

```
传统注意力: O(L²)
RWKV: O(L)且可并行训练
```

**时间混合（Time Mixing）**
```python
def time_mixing(x, state):
    # 线性插值
    x_shifted = lerp(x, state['x_prev'], time_decay)

    # 通道混合
    r = sigmoid(W_r @ x)
    k = W_k @ x_shifted
    v = W_v @ x_shifted

    # WKV (Weighted Key-Value)
    wkv = r * (state['wkv'] / (state['wkv_sum'] + eps))

    # 更新状态
    state['wkv'] = state['wkv'] * time_decay + k * v
    state['wkv_sum'] = state['wkv_sum'] * time_decay + k

    return wkv, state
```

**空间混合（Channel Mixing）**
```python
def channel_mixing(x, state):
    x_shifted = lerp(x, state['x_prev'], time_decay)

    r = sigmoid(W_r @ x)
    k = W_k @ x_shifted

    return r * (W_v @ torch.relu(k) ** 2), state
```

**并行化WKV**
```python
def parallel_wkv(k, v, w):
    """
    并行计算WKV
    k: [B, L, D]
    v: [B, L, D]
    w: 时间衰减
    """
    # Prefix Sum with Decay
    wkv = torch.cumsum(k * v * w, dim=1) / \
          (torch.cumsum(k * w, dim=1) + eps)

    return wkv
```
