# 回测框架设计

## 核心架构

### 事件驱动模式
避免前视偏差（Look-ahead Bias），模拟真实交易流程。

```
市场数据 → 策略信号 → 订单生成 → 订单执行 → 持仓更新
```

## 关键组件

### 1. 数据处理器
- **历史数据加载**：CSV、数据库、API
- **数据清洗**：缺失值、异常值处理
- **对齐处理**：不同标的时间对齐

### 2. 策略引擎
- **信号生成**：基于技术指标、基本面等
- **仓位管理**：Kelly公式、固定比例等
- **风险控制**：止损、止盈、最大持仓

### 3. 执行模拟
- **滑点模拟**：市价单滑点
- **手续费**：交易佣金、印花税等
- **成交延迟**：模拟真实成交时间

### 4. 绩效分析
- **权益曲线**：资金变化曲线
- **回撤分析**：最大回撤及持续时间
- **交易统计**：胜率、盈亏比等

## 常见陷阱

### 前视偏差
**错误示例**：使用当天收盘价判断并当天成交
**正确做法**：T日信号 → T+1日开盘执行

### 幸存者偏差
**问题**：只用当前存续股票回测
**解决**：使用历史全样本数据，包括退市股

### 过度拟合
**问题**：参数优化过度，历史表现好但实盘差
**解决**：
- 样本外测试
- Walk-forward分析
- 减少参数数量

## 性能指标

### 收益类
- **年化收益率**：总收益率 × (365/天数)
- **累计收益**：期末/期初 - 1
- **月度收益**：每月收益统计

### 风险类
- **最大回撤**：从峰值到谷底的最大跌幅
- **年化波动率**：日收益率标准差 × √252
- **下行波动率**：只计算负收益波动

### 综合类
- **夏普比率**：(年化收益 - 无风险利率) / 年化波动率
- **索提诺比率**：(年化收益 - 无风险利率) / 下行波动率
- **卡玛比率**：年化收益 / 最大回撤

## 实战建议

1. **先简单后复杂** - 从买入持有基准开始
2. **多维度验证** - 不同市场环境、不同品种
3. **保留历史版本** - 追踪策略演化
4. **文档化假设** - 记录每次优化的原因和结果
