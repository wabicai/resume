# 风险管理实践

## 风险分类

### 市场风险
- **价格风险**：标的价格波动
- **流动性风险**：无法及时平仓
- **波动率风险**：隐含波动率变化

### 操作风险
- **模型风险**：策略失效
- **技术风险**：系统故障
- **人为风险**：操作失误

### 合规风险
- **监管风险**：政策变化
- **税务风险**：税收政策
- **法律风险**：合同纠纷

## 风险度量

### VaR（在险价值）
**定义**：在给定置信水平下，未来特定时间内的最大可能损失

```
VaR(95%) = 投资组合价值 × 1.65 × 日波动率
```

**方法**
- 历史模拟法：基于历史数据
- 方差-协方差法：假设正态分布
- 蒙特卡洛法：随机模拟路径

### CVaR（条件在险价值）
超过VaR时的平均损失，更关注尾部风险。

### 最大回撤
从峰值到谷底的最大跌幅：
```
最大回撤 = (峰值 - 谷底) / 峰值
```

### 夏普比率
风险调整后收益：
```
夏普比率 = (年化收益 - 无风险利率) / 年化波动率
```

## 风控措施

### 1. 仓位控制

**固定比例法**
- 单标的持仓≤总资产10%
- 单板块持仓≤总资产30%

**Kelly公式**
```
f = (p × b - q) / b
f: 投入比例
p: 胜率
b: 赔率
q: 败率(1-p)
```

**风险平价**
```
每个资产的风险贡献 = 资产权重 × 资产波动率
保持所有资产风险贡献相等
```

### 2. 止损策略

**固定止损**
- 单笔亏损≤本金2%
- 日亏损≤本金5%
- 周亏损≤本金10%

**移动止损**
```
止损价 = MAX(入场价×(1-止损%), 最高价×(1-回撤%))
```

**时间止损**
- 持仓超过N天未盈利则平仓
- 避免死扛

### 3. 风险对冲

**Delta对冲**
- 用期货/期权对冲现货风险
- 保持Delta中性

**行业对冲**
- 多空配对：做多强势股，做空弱势股
- 市场中性策略

**跨期对冲**
- 利用不同到期日合约
- 对冲展期风险

## 实时监控

### 关键指标

**持仓监控**
- 实时PnL
- 持仓集中度
- 杠杆率

**风险指标**
- 实时VaR
- Beta暴露
- 希腊字母（期权）

**流动性指标**
- 可用资金
- 保证金占用率
- 强平风险

### 预警机制

**三级预警**
1. **黄色预警**：单日亏损3%
   - 减少交易频率
   - 严格执行止损

2. **橙色预警**：单日亏损5%
   - 停止新开仓
   - 减仓50%

3. **红色预警**：单日亏损8%
   - 全部平仓
   - 停止交易
   - 复盘检讨

### 自动化处理

```python
class RiskManager:
    def check_position_risk(self, position):
        # 检查仓位风险
        if position.unrealized_pnl < -self.stop_loss:
            self.close_position(position)

    def check_portfolio_risk(self):
        # 检查组合风险
        if self.portfolio.daily_pnl < -self.daily_limit:
            self.emergency_stop()

    def emergency_stop(self):
        # 紧急止损
        self.close_all_positions()
        self.send_alert("触发紧急止损")
```

## 压力测试

### 历史情景
- 2008金融危机
- 2015股灾
- 2020疫情

### 假设情景
- 单日暴跌10%
- 流动性枯竭
- 系统故障

### 测试内容
- 最大亏损
- 资金缺口
- 平仓能力

## 危机应对

### 应对预案

**流动性危机**
1. 优先平仓流动性好的标的
2. 申请信用额度
3. 变卖非核心资产

**系统故障**
1. 切换备用系统
2. 手动下单平仓
3. 联系券商应急

**黑天鹅事件**
1. 立即停止交易
2. 评估损失
3. 调整策略

### 事后复盘

**分析维度**
- 风险源识别
- 损失路径分析
- 应对措施评估
- 改进方案制定

**持续改进**
- 更新风控模型
- 优化预警阈值
- 完善应急预案

## 最佳实践

1. **永远不要满仓** - 保留20%现金应急
2. **分散投资** - 不要all-in单一策略
3. **定期复盘** - 每周/每月风险回顾
4. **模拟演练** - 定期压力测试
5. **纪律至上** - 严格执行风控规则

## 常见误区

❌ **误区1**：历史回测好就能实盘
- 市场环境会变化
- 需要持续验证

❌ **误区2**：止损会错过反弹
- 小损失好过大亏损
- 可以重新进场

❌ **误区3**：分散就是风控
- 相关性高的分散无意义
- 关注真实风险敞口

❌ **误区4**：技术能解决一切
- 人的判断不可少
- 极端情况需人工介入
