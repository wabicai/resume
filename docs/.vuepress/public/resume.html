面向 Agent 的硬件钱包 CLI

工具基础设施 / 会话管理

TypeScript · Node.js · Hardware SDK · EVM · CLI · macOS Keychain / pinentry

实现 OneKey CLI 的硬件钱包登录、签名分发和设备管理，支持 AI 非交互调用场景，使命令行任务能够复用钱包底层能力。

  • 签名路由：按链和钱包类型组织签名器，将凭据获取下沉至具体实现；抽取 EVM 交易构建逻辑，供客户端与 CLI 共用。
  • 非交互调用：补充隐藏钱包输入模式参数，避免 AI 调用依赖交互式菜单；处理多设备选择与设备绑定，让后续命令定位正确的硬件。
  • 会话生命周期：复用有效的设备会话与隐藏钱包状态，在设备锁定或会话失效后重新认证，减少重复输入并保持钱包上下文一致。
  • 凭据与验证：修复系统凭据存储调用中的密码暴露问题，校验特殊字符输入；覆盖登录、签名器选择、设备锁定恢复和退出清理等流程。
