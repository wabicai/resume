面向 Agent 的硬件钱包 CLI

命令行钱包能力 · 非交互调用

让硬件钱包登录、签名和设备选择可以被命令行及 AI 工具稳定调用，而不依赖交互式菜单。

  • 签名路由：按链与钱包类型组织签名器，抽取 EVM 交易构建逻辑供客户端和 CLI 共用。
  • 设备上下文：处理多设备选择、会话复用和隐藏钱包输入；设备锁定或会话失效后重新认证。
  • 凭据安全：修复系统凭据存储调用中的密码暴露问题，校验特殊字符输入及退出清理。
