# 7.小程序同层渲染

## 什么是同层渲染

早期小程序里，原生组件和 WebView 渲染层级不同，常出现遮挡、覆盖和事件穿透问题。同层渲染的目标，就是让原生组件和页面内容尽量处于统一层级体系里，减少这类问题。

## 解决了什么

- 视频、地图、输入框不再总是“压住一切”
- 弹窗、浮层、定位元素更容易正常展示
- 页面交互一致性更好

## 适用场景

- 页面里存在视频、地图、canvas 等原生能力组件
- 复杂弹窗、吸顶、浮层与原生组件混用

## 注意点

- 同层渲染提升了体验，但并不意味着完全没有兼容差异。
- 某些端能力、某些老版本基础库仍可能表现不一致。
- 涉及复杂层级时仍建议真机验证。
