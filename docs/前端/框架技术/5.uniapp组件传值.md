# 5.uniapp 组件传值

## 父传子

最常见方式是 `props`。父组件通过属性传值，子组件通过 `props` 接收。

## 子传父

通过 `$emit` 触发事件，把结果回传给父组件。

## 跨层传递

- 简单场景：逐层透传 props / emit
- 复杂场景：可以借助全局状态或事件中心

## 常见注意点

- 传对象和数组时，不要在子组件里直接修改。
- `props` 适合“输入”，事件适合“输出”，职责要清晰。
- UniApp 运行在多端时，尽量避免依赖只在某一端成立的事件细节。

## 建议

组件传值优先遵循“单向数据流”，简单可靠，也更容易排查问题。
