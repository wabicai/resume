# 简历

## 个人方向

- 前端工程化与性能优化
- H5 活动页、低代码平台与小程序实践
- Node 服务治理、监控告警与自动化巡检
- 持续沉淀前端、后端与计算机基础知识

## 核心技术栈

- 前端：JavaScript、TypeScript、Vue、React、UniApp、小程序
- 工程化：Webpack、Vite、pnpm、Monorepo、CI/CD、GitHub Pages
- 服务端：Node.js、Golang、MySQL
- 基础能力：网络、操作系统、设计模式、性能分析与问题排查

## 项目实践关键词

- 移动端适配、图片压缩、预渲染、接口缓存、页面提速
- 低代码表达式解析、配置化渲染、组件动态加载
- 基于 Puppeteer 的截图巡检、SSR 页面处理与自动化测试
- 服务治理、链路追踪、日志推送与告警体系建设
